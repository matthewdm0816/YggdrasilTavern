# 试验性语音朗读（TTS）

入口：聊天输入框上方的“语音朗读设置”，或左侧“设置 → 语音朗读（试验）”。

## 首次配置 MiniMax

1. 保持“启用语音朗读”关闭，填写完整接口地址和 API Key，保存。
2. 点击“获取 MiniMax 音色”，选择或填写音色 ID。也可以直接填写已有音色 ID。
3. 选择模型、语速等参数，开启“启用语音朗读”并保存。触发方式默认“手动”。

当前官方国内接口为 https://api.minimax.cn/v1/t2a_v2，国际接口为 https://api.minimax.io/v1/t2a_v2。按 API Key 所属平台配置。地址与模型可编辑。也支持返回 MP3 的 OpenAI 兼容 /audio/speech 接口，包括无需密钥的本地服务。

每个账号独立保存连接、密钥和朗读选项。密钥不会回传到浏览器；修改服务商或地址时，需要重新输入密钥或明确清除旧密钥。

## 两种文本来源

- **自动提取引号内的人物发言**：识别中英日引号及嵌套引号，跳过星号动作、代码、HTML 注释和思考标签。没有完整匹配时返回空，不回退为全文朗读。它使用引号规则，不是语义分类；未加引号的台词可改用标签或在手动预览中填写。
- **只读 <tts>...</tts> 标签内容**：只提取完整标签块。可选“自动提示模型添加标签”，该提示只加入当次上下文，不修改已保存的全局 prompt。消息正文隐藏包装标签，编辑原文时保留标签。

两种模式都保留 MiniMax 的停顿标记 <#0.5#> 与 (laughs)、(sighs) 等语气文本。不会发送消息的独立 Thinking 字段。

## 手动与自动播放

手动模式：角色消息的“...”菜单 → “朗读消息…” → 检查或调整本次朗读文本 → “合成并播放”。预览不调用语音供应商，文本编辑只影响本次朗读。

自动模式：只处理当前会话中新生成完成且仍在当前分支的角色消息。打开历史会话、刷新页面、修改消息或切换 swipe 不会触发重读。切换会话、关闭 TTS、修改连接或点击“停止朗读”会中止排队与播放。

若浏览器阻止播放，点击“播放已生成音频”即可继续，不会重复请求语音服务。输出按 MP3 处理；响应大小和请求时间设有限制，失败会在页面显示原因。音频不会写入服务器文件。

单次文本上限：MiniMax 9999 字符；OpenAI 兼容接口 4096 字符。超过时请在手动预览中缩短，系统不会静默截断。
