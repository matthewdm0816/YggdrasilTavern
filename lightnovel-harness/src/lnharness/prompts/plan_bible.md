# 任务
根据作者的企划书，整理出一份可以长期使用的设定集。

# 企划书
$premise

# 要求
- 角色：主角、女主角（或主要搭档）、2~4 名有独立目的的配角、对手或反派。每个角色都要写清"表面上想要的东西"和"真正需要的东西"，以及会制造冲突的缺点。配角不是主角的附属品。
- 口吻要彼此可区分：一人称、敬语程度、口癖、句尾习惯都要不同。示例台词要能体现性格，遮住名字也能认出是谁。
- 称呼表：主要角色之间初始怎么互相称呼。称呼的变化以后会用来表现关系进展，所以初始称呼要留出变化的空间（例如从姓氏+同学，到名字，到昵称）。
- 能力/战力体系：每个能力都必须写清代价和限制。限制比能力本身更重要——它决定了以后能写出多少有趣的困境。不要万能的能力。如果读者一开始不知道某个能力存在，或者它的代价本身是个谜，用 concealed_until / cost_concealed_until 关联到对应的谜团。
- 谜团：读者会在故事中好奇的问题和真相。真相要能被事先埋下线索。
- 母题：2~4 个会反复出现、而且意义会随故事变化的意象、物件或动作（可以包含一个 running gag）。
- 主题：用一个问题的形式写出。作品最终要用主角的选择来回答它。
- 所有 id 只用小写英文字母、数字和下划线；谜团 id 用 M1、M2 这样的格式。
$revision
