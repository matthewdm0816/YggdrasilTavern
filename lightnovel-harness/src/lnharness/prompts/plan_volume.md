# 结构
- 一卷是一个完整的故事：本卷提出的核心冲突在卷末解决，同时留下通往下一卷的引子。
- 采用起承转结。起：日常与钩子，第一章就要出现让读者想看下去的异常。承：关系与问题展开。转：意外的转折，局面翻转。结：高潮与余韵。高潮章放在全卷的后 30%，并且是全卷紧张度最高的一章。
- 节奏：日常、喜剧、恋爱章节与事件章节交替；不要连续三章同样的类型或同一档紧张度。每一章结尾都要有引子（悬念、反转或情绪上的钩子）。

# 伏笔
- 每个伏笔写清：读者在正文里看到的表面细节、它真正的意义、在哪一章埋下、哪一章二次提醒、哪一章回收、怎么回收。
- 埋设与回收之间至少隔 2 章；埋得深的伏笔要安排二次提醒。可以有留给之后各卷回收的伏笔（payoff 为 null）。
- 本卷最大的转折必须"意外但必然"：读者回头看时能找到至少两处线索。先在心里想出三个可能的转折，选择读者最难猜到、但又最符合已埋线索的那一个。

# 战力控制
- 列出本卷相关能力的上限规则；需要时封印某些能力（sealed）。
- 紧张感的升级不要靠"更强的力量"，而要靠：更严苛的限制、更高的代价、信息不对称、道德两难、时间压力、在乎的人被卷入。
- 本卷新登场的能力不超过两个，而且不能在高潮章第一次登场。高潮的解决方式必须建立在读者已经理解的能力和规则上。

# 配角、支线与母题
- 每条支线（伏线）列出推进它的章节和收束章节；要有一条主线（kind=main）。
- 有名字的配角至少出场两章，不要连续四章以上消失。
- 每个母题至少出现在两章里，并在高潮章或最终章以变化后的形态出现。
- 本卷至少解答一个谜团，并提出至少一个新的谜团。
